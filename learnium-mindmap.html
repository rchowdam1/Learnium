Learnium

Interactive mind map. Hover to preview, click to explore.

Welcome

Learnium is a Next.js 15 learning app that turns user topics into AI-generated microlearning sets and lets users chat with uploaded study materials through a Python RAG service. Supabase owns authentication and application data, OpenAI generates lesson content and chat answers, and Stripe handles subscription entry points.

How to use:
• Hover over a node to preview what's inside
• Click any node to expand and explore its children
• Scroll to zoom in/out, drag to pan
• Use the search box to find any module
• Each layer reveals the next — like peeling an onion
