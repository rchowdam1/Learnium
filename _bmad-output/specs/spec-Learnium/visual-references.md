# Learnium Visual References

The mockups folder is a visual reference set, not token authority:

`../../planning-artifacts/ux-designs/ux-Learnium-2026-07-05/mockups/`

`DESIGN.md` wins for color, typography, radii, component styling, token names, elevation, and brand voice. `EXPERIENCE.md` wins for information architecture, behavior, accessibility, states, flows, and copy rules.

## Accepted Mockup Direction

- Landing, signup, login, and onboarding references define restrained composition, not final copy or accessibility completeness.
- Dashboard and Learn references support the two-zone desktop composition and mobile stacking of metrics, Reviews, and active learning cards.
- Learning Path and Lesson Chain references support vertical timeline progression with explicit locked, active, and complete affordances.
- Lesson, quiz, Review, and Review Summary references support focused full-screen learning with top progress and large answer cards.
- Nova chat references support lesson-context header, message alternation, visible thinking state, fixed composer, quota row, and out-of-quota handling.
- Paywall, profile, public profile, League, and settings references support reassurance-first billing, privacy-limited social display, weekly standings, and clean settings grouping.
- Celebration, level-up, share card, logo, Nova, and badge references support concentrated reward energy and the North Star visual motif.

## Rejected Mockup Drift

- Generated palettes, broad gradients, 24px card radii, heavy shadows, and abstract/fake preview media do not override `DESIGN.md`.
- Mockup omissions of skip links, ARIA labels, focus handling, reduced motion, age-gate accessibility, or real controls do not relax `EXPERIENCE.md`.
